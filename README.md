#Find My Things 

##Find My Things is an iOS application that allows users to track their important Bluetooth-enabled items (e.g., AirPods, Bluetooth speakers, keychains) by detecting them based on proximity. The app uses Core Bluetooth to scan nearby devices and Core Location to track the user's location. With this app, users can easily locate lost items by checking their proximity and viewing the last known location.

#Technologies Used
 **SwiftUI for building the user interface.
 **Core Bluetooth for Bluetooth scanning and interaction.
 **Core Location for location tracking and geofencing.
 **MapKit for displaying maps and tracking locations.
